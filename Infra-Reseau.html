PROJET PERSONNEL — JUNGTECH

Infrastructure systèmes & réseaux

Mise en place d'une infrastructure réseau virtualisée complète comprenant un réseau interne, un serveur DHCP, un serveur DNS, un contrôleur de domaine Samba Active Directory et un serveur de fichiers Samba.

← Retour au portfolio

Présentation

JungTech est un laboratoire d'infrastructure réalisé sous VirtualBox afin de reproduire un environnement informatique d'entreprise.


L'objectif était de mettre en place une infrastructure permettant à des postes Windows d'obtenir automatiquement leur configuration réseau, de résoudre les noms internes, de s'authentifier sur un domaine Active Directory et d'accéder à des ressources partagées selon leurs droits.

Infrastructure réseau

Réseau interne

Réseau VirtualBox dédié au laboratoire : JungTech-Network

Adressage

Réseau IPv4 : 192.168.10.0/24

DHCP

VM01 attribue automatiquement les adresses IP de 192.168.10.100 à 192.168.10.200.

DNS

BIND9 fournit la résolution DNS interne du domaine jungtech.local.

VM01 — Serveur réseau

DHCP

Attribution automatique des paramètres réseau aux postes clients.

BIND9

Gestion de la résolution DNS du réseau interne.

Samba

Hébergement des partages de fichiers réseau.

Winbind

Permet à Linux d'utiliser les utilisateurs et groupes provenant de l'Active Directory.

VM02 — Contrôleur de domaine

VM02 héberge le contrôleur de domaine Samba Active Directory.


  • Domaine : JUNGTECH.LOCAL
  • NetBIOS : JUNGTECH
  • Contrôleur : DC01
  • Adresse IP : 192.168.10.20

Le contrôleur centralise les comptes utilisateurs, les groupes et l'authentification du domaine.

Active Directory

Utilisateurs

Alice et Bob sont gérés directement dans l'Active Directory.

Groupes

Les groupes Direction et Comptabilite permettent d'organiser les droits d'accès.

LDAP

LDAP permet aux services du domaine d'accéder aux informations de l'annuaire.

Kerberos

Kerberos fournit le mécanisme d'authentification utilisé au sein du domaine.

Gestion des droits

Les accès aux ressources sont organisés à partir des groupes Active Directory.


  • Alice → groupe Direction → partage Direction
  • Bob → groupe Comptabilite → partage Comptabilite
  • Commun → partage accessible aux utilisateurs autorisés

Cette organisation permet de centraliser la gestion des utilisateurs et d'appliquer les droits en fonction de leur groupe.

Poste client Windows

  • Adresse IP obtenue automatiquement par DHCP
  • DNS fourni automatiquement par DHCP
  • Résolution du domaine jungtech.local
  • Authentification avec un compte Active Directory
  • Accès aux partages Samba
  • Application des droits selon les groupes AD
